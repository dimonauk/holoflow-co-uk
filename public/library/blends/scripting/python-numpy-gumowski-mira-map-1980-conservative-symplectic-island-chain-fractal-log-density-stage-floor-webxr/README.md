# Gumowski–Mira Map (1980) — Conservative Symplectic Island Chains, Log-Density Height-Field

**I. Gumowski & C. Mira 1980 · Blender 5.1 · CC0**

A 2-D area-preserving symplectic recurrence rendered as a 128 × 128
log-density height-field stage floor for WebXR — where KAM tori and
chaotic seas coexist in the same phase portrait.

---

## The mathematics

```
G(x) = μ·x  +  2·(1−μ)·x² / (1 + x²)

x_{n+1} = y_n + G(x_n)                         step (1)
y_{n+1} = −x_n + G(x_{n+1})       (uses updated x' from step 1)
```

The Jacobian determinant is **exactly 1** for all (x, y):

```
det J = G'(x)·G'(x') − (−1 + G'(x')·G'(x)) = 1   ✓
```

This is a symplectic (area-preserving / canonical) transformation: no
volume contraction, no global strange attractor.  The KAM theorem guarantees
closed invariant tori near elliptic fixed points; beyond the *last invariant
torus* lies the chaotic sea.

### Why G(x) has this form

`2x²/(1+x²)` is a rational sigmoid that saturates to 2 for `|x| → ∞`.
This bounds all orbits globally — no escape to infinity — while the linear
term `μx` controls the **twist rate** at the origin.  At `μ=0` the map
reduces to a pure quadratic fold; at `μ=±1` the fold vanishes and the map
degenerates to a simple shear with no chaos.

### Fixed points

The origin O=(0,0) is always a fixed point:
`G(0)=0` → x'=0+G(0)=0, y'=0+G(0)=0. ✓

Linearised at the origin: eigenvalues satisfy
`λ² − (G'(0)² + G'(0)² − 1)λ + 1 = 0` → `λ² − (2μ²−1)λ + 1 = 0`.
For `|μ| < 1/√2` the eigenvalues are complex with `|λ|=1` (elliptic),
so the origin is surrounded by KAM tori.

## Shape keys

| Key | μ | Character |
|-----|---|-----------|
| Basis | −0.496 | Gumowski–Mira galaxy: intricate island chains with large chaotic sea |
| SK_Ring | −0.120 | Flower / concentric-ring topology, predominantly KAM tori |
| SK_Web | −0.450 | Dense island-chain web, intermediate chaos level |
| SK_Fish | +0.008 | Large central elliptic island, "fish-eye" appearance, small chaotic zone |

### Density method

200 orbits (y₀=0, x₀ ∈ [−3.8, +3.8]) × 25 000 iterations each = **5 M points**
per shape key, accumulated via `np.histogram2d` into a 128 × 128 grid.
`log(1 + count)` compresses the 3-decade dynamic range so both the dense
KAM tori and the sparse chaotic filaments contribute readable Z geometry.

## Lyapunov structure (Basis, μ = −0.496)

| Quantity | Value |
|----------|-------|
| Largest Lyapunov exponent (chaotic orbits) | λ₁ ≈ +0.25 (positive) |
| Largest Lyapunov exponent (KAM orbits) | λ₁ = 0 (quasi-periodic) |
| Area contraction | exactly 0 (det J = 1) |
| Kaplan–Yorke dimension | N/A (not a dissipative system) |

Orbits in the chaotic sea have λ₁ > 0 (exponential divergence); orbits
on KAM tori have λ₁ = 0 (neutral stability).  The coexistence of both
in one map is the defining feature of the mixed phase space.

## Running

1. Open Blender 5.1 with a new scene.
2. Open the **Scripting** workspace.
3. Load `blueprint.py` and press **Run Script** (▶).
4. Wait for the four progress messages then check the console for the GLB path.
5. Load `record.py` and press **Run Script** to render `viewport.mp4`.
