# Talbot Effect (1836) — Near-Field Self-Imaging, Fractional Talbot, Gauss-Sum Height-Field

**H. F. Talbot 1836 / M. V. Berry & S. Klein 1996 · Blender 5.1 · CC0**

A Huygens–Fresnel paraxial diffraction carpet rendered as a 128 × 128
log-intensity height-field stage floor for WebXR — where periodic gratings
create near-field self-images at integer multiples of the Talbot length.

---

## The mathematics

### Paraxial propagation

Each Fourier harmonic of a grating with period d propagates as a tilted
plane wave.  In the Fresnel approximation, the far-axis phase after
propagating distance z is:

```
phase of harmonic n  =  −π n² λ z / d²
```

The full field is:

```
U(x, z) = Σ_{n=−N}^{N}  c_n · exp(2πinx/d) · exp(−iπn²λz/d²)
```

The **Talbot length** z_T = 2d²/λ is the propagation distance that makes
each phase factor equal 1 for every integer n, restoring U(x, 0) exactly:

```
exp(−iπ n² λ z_T / d²)  =  exp(−2πin²)  =  1   for all n ∈ ℤ   ✓
```

### Fractional Talbot images and Gauss sums

At z = (p/q)·z_T (a rational fraction with gcd(p,q) = 1), each phase factor
becomes exp(−2πin²p/q).  Berry & Klein (1996) showed that the intensity
decomposes into q copies of the grating shifted by multiples of d/q:

```
I(x, (p/q)z_T)  =  (1/q) Σ_{k=0}^{q−1}  |S(p,q,k)|²  · |t(x − kd/q)|²
```

where S(p,q,k) = Σ_{n=0}^{q−1} exp(2πin²p/q + 2πink/q) is a Gauss sum.
For q=2 (half Talbot distance), the image is a copy shifted by d/2, which
is why a binary grating appears identical but displaced.  For q=3 the carpet
shows three interleaved copies, and so on.

At irrational z/z_T, the intensity is a fractal measure of Hausdorff
dimension 3/2 — the mathematical fabric of the "Talbot carpet".

### Fixed points of the grating mapping

The origin x=0, z=0 is always a trivial fixed point.  The self-imaging
condition I(x, z_T) = I(x, 0) is a fixed-point equation for the
propagation super-operator on the space of periodic intensity distributions.
Every grating profile is a fixed point of this operator modulo d-shifts.

## Shape keys

| Key | Grating | c_n |
|-----|---------|-----|
| Basis | Binary (square wave, 50% duty) | c_n = sin(nπ/2)/(nπ) |
| SK_Sine | Sinusoidal | c_0=0.5, c_±1=0.25, else 0 |
| SK_Blazed | Blazed (sawtooth 0→1) | c_0=0.5, c_n=i/(2πn) |
| SK_Phase | Binary ±1 phase | c_0=0, c_n=2/(iπn) odd n only |

### Computation

For each grating type: build the (2N+1) Fourier coefficient array, compute
x-modes (GRID_N × 2N+1) and z-modes (GRID_N × 2N+1) via broadcasting, then
the intensity carpet as a single matrix multiply:

```python
cx_modes = cn[None, :] * x_modes          # (GRID_N, 2N+1)
U        = cx_modes @ z_modes.T           # (GRID_N, GRID_N)
I        = |U|²
height   = log1p(I) / max(log1p(I))
```

`log1p` compresses the intensity range so both the bright self-images
(high I) and the dark interference minima (low I) contribute legible geometry.

## Lyapunov / stability structure

The Talbot effect is a linear optical phenomenon — no chaos, no attractors.
The relevant "stability" is the **Talbot stability condition**: a small
wavelength perturbation δλ shifts the self-imaging plane by δz = 2d²δλ/λ²,
which for δλ/λ = 1% gives δz = 0.02·z_T.  This is why broadband sources wash
out the carpet (temporal coherence requirement).
