# Allen–Cahn Phase-Field Equation: Interface Motion by Mean Curvature

**Blender 5.1 | Python + numpy | Stage floor for WebXR**

---

## What this is

A 128 × 128 height-field stage floor generated by integrating the
**Allen–Cahn equation** — the gradient flow of the Ginzburg–Landau free
energy — using the ETD1 (Exponential Time Differencing) scheme.

A scalar order parameter φ(x,y,t) ∈ [−1,+1] evolves from small random
perturbations toward two stable phases (φ = ±1):

- **φ = +1** → amber peaks (one thermodynamic phase)
- **φ = −1** → cobalt valleys (the other phase)
- **φ ≈ 0** → interface (domain wall), vanishingly thin for small ε

Unlike the Cahn–Hilliard equation (conserved composition), Allen–Cahn is
**non-conserved**: small domains shrink and disappear while large ones grow.
This is *motion by mean curvature*: the normal velocity of each interface
equals ε × (local curvature).

---

## Mathematics

```
∂φ/∂t = ε²∇²φ − F′(φ)             (Ginzburg–Landau gradient flow)
F(φ)   = ¼(1 − φ²)²               (double-well free energy)
F′(φ)  = φ³ − φ                   (zero at φ = −1, 0, +1)

After splitting:  ∂φ/∂t = L̂φ + N(φ)
  L̂φ  = ε²∇²φ + φ    (linear operator; Fourier eigenvalue λ_k = 1 − ε²k²)
  N(φ) = −φ³          (nonlinear reaction term only)
```

**Sharp-interface limit:** interfaces move with normal velocity v_n = ε κ,
where κ is the local mean curvature. Circular islands shrink as
R(t)² ≈ R₀² − 2ε²t.

**Coarsening law:** ⟨L(t)⟩ ∼ t^(1/2) — faster than Cahn–Hilliard's t^(1/3)
because Allen–Cahn eliminates the slower surface-diffusion mechanism.

---

## Numerical method — ETD1

```
ETD1 (Cox & Matthews 2002):

λ_k   = 1 − ε²k²                    # linear Fourier eigenvalue
E_k   = exp(λ_k · dt)               # exact linear propagator
φ₁(z)  = expm1(z)/z                  # ETD weight (stable near z=0)

φ̂(t+dt) = E_k · φ̂(t) + φ₁(λ_k dt)·dt · F̂{−φ(t)³}
```

WHY ETD1 over semi-implicit: the linear operator L̂ has eigenvalues that
cross zero at k² = 1/ε². A semi-implicit denominator near zero produces
near-singular factors; ETD1 avoids this by using the exact propagator.
High-k modes decay to zero in O(1) steps regardless of dt.

## Parameters

| Constant | Value | Role |
|---|---|---|
| N | 128 | Grid resolution (128 × 128 = 16 384 vertices, 16 129 quads) |
| ε (Basis) | 0.020 | Interface thickness — sets domain wall width |
| ε (SK_Fine) | 0.012 | Sharper interfaces, finer-scale texture |
| ε (SK_Broad) | 0.040 | Diffuse interfaces, softer domain walls |
| dt | 0.10 | ETD1 time step |
| STEPS_BASIS | 100 | t = 10 — rapid nucleation, many blobs |
| STEPS_COARSE | 600 | t = 70 — moderate coarsening applied on top |

## Shape keys

| Key | ε | t | Description |
|---|---|---|---|
