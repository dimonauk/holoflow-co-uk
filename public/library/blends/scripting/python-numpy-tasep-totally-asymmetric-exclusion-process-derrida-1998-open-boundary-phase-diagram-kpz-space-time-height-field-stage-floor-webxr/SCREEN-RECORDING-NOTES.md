# Screen-Recording Notes — TASEP Kymograph

These notes tell you how to capture `screen.mp4` for this library entry.
`viewport.mp4` is generated by `record.py`; `screen.mp4` shows the live
Blender workflow of pasting and running the blueprint.

## Setup

| Setting | Value |
|---|---|
| Source | Window — Blender (fullscreen or maximised) |
| Resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Off (no mic needed) |
| Output | `screen.mp4` |

## OBS Studio steps

1. **Sources → + → Window Capture** → select the Blender window.
2. Right-click canvas → **Transform → Fit to Screen**.
3. In Recording settings: MP4, H.264, CRF 23.
4. **Start Recording**.

## Windows Game Bar (Win + G)

1. Open Blender, press **Win + G** → click the camera icon (Record).
2. Confirm the window is Blender (not the desktop).
3. Press **Win + Alt + R** to begin.

## What to show on screen (target: 5–10 minutes)

1. **File → New → General** to reset Blender to a blank scene.
2. Switch to the **Scripting** workspace (top tabs).
3. **New** script, paste `blueprint.py` in full.
4. Talk through the key sections:
   - `_step()` — conflict-free synchronous update, bulk hops, boundaries.
   - `run_tasep()` — burn-in + kymograph collection.
   - `build_floor_mesh()` — direct data API (no `bpy.ops.mesh`).
   - Shape key structure: Basis (LD), SK_HDphase (HD), SK_MaxCurr (MC), SK_Shock.
5. **Run Script** (▶). Console shows phase labels and ✓ confirming GLB written.
6. Switch to **Layout** workspace, select `tasep_floor`.
7. Open **Properties → Object Data → Shape Keys**.
   Drag the `SK_Shock` value slider 0→1 to show the shock domain wall.
8. Open **Properties → Object Data → Color Attributes** — show `TASEP_Density`.
9. Cycle through the four shape keys in the 3-D viewport (numpad 7 = top view).
10. **File → Export → glTF 2.0** and briefly explain Draco + morph-target settings.
