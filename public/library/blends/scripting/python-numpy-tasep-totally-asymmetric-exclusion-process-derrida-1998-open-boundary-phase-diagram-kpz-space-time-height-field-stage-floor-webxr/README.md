# TASEP — Totally Asymmetric Simple Exclusion Process

**Blender 5.1 · Python + NumPy · Stage-floor height field · WebXR**

## What this is

A 128 × 128 kymograph of the open-boundary TASEP baked into a quad-grid
stage floor with four shape keys representing the three phases and the
first-order shock line.  Each vertex height = local particle density
averaged over 32 time steps.  Colour runs Cobalt (empty) → Amber (full).

## Physics

The TASEP is a 1-D lattice gas in which particles hop rightward at rate 1
under hard-core exclusion.  Left and right reservoirs inject/absorb at
rates α and β.  The model is exactly solvable via the matrix-product
ansatz (Derrida et al. 1993) and hosts three phases:

| Phase | Condition | ρ_bulk | J |
|---|---|---|---|
| Low-density (LD) | α < 1/2, α < β | α | α(1−α) |
| High-density (HD) | β < 1/2, β < α | 1−β | β(1−β) |
| Maximal current (MC) | α, β ≥ 1/2 | 1/2 | 1/4 |

At α = β < 1/2 (first-order coexistence), a macroscopic shock executes a
symmetric random walk with diffusion constant D ≈ J/L.

**KPZ universality** — current fluctuations scale as t^{1/3} with a
Tracy–Widom GUE distribution; TASEP is the canonical exactly-solvable
KPZ model.

```bash

```

Or open Blender → Scripting workspace → paste `blueprint.py` → Run Script.

## Shape keys

| Key | α | β | Phase |
|---|---|---|---|
| Basis | 0.30 | 0.70 | LD — sparse drift |
| SK_HDphase | 0.70 | 0.30 | HD — dense, holes drift left |
| SK_MaxCurr | 0.80 | 0.80 | MC — half-density, max current J=1/4 |
| SK_Shock | 0.30 | 0.30 | Shock — mobile domain wall |
