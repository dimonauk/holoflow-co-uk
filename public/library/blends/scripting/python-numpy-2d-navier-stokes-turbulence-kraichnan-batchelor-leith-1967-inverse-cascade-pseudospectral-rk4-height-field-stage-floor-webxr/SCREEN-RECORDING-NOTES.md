# Screen Recording Notes — NS2D Turbulence Floor

## Software
OBS Studio (Windows Game Bar also works).

## Setup
- Source: **Window Capture** → select the Blender 5.1 window.
- Resolution: 1920 × 1080.
- Frame rate: 30 fps.
- Audio: **off** (no mic, no desktop audio).
- Output format: MKV (convert to MP4 afterwards with `ffmpeg -i raw.mkv screen.mp4`).
- Filename: `screen.mp4` → place in `public/library/videos/scripting/<slug>/`.

## Blender viewport settings before recording
1. Open `ns2d_turbulence_floor.blend`.
2. Set viewport shading to **Rendered** (EEVEE Next).
3. Set viewport background to black: World Properties → Viewport Display → Colour = `#080808`.
4. Position camera overhead with slight angle: `Numpad 0` to enter camera view.
5. Maximise the 3D viewport: `Ctrl + Space`.

## Recording sequence (~ 3 minutes total)
1. **Run `blueprint.py`** in the Blender scripting editor — narrate what each section does as it runs. The computation takes 20–60 s; keep the progress print visible.
2. **Shape key walkthrough** — open the Properties panel (N key) → Object Data → Shape Keys. Manually scrub each key value from 0 → 1 while narrating:
   - **Basis**: early turbulence, many small eddies at forcing scale k = 6.
   - **SK_Cascade**: inverse cascade beginning — larger structures appear.
   - **SK_Condensed**: coherent dipole vortex condensation.
   - **SK_Forced**: saturated forced state, domain-scale coherent vortex.
3. **Rotate the viewport** to show height variation (the vorticity field raised as a hill).
4. **GLB in Three.js / WebXR** — if time permits, drag the GLB into a browser console and show morphTargetInfluences animating between keys.

## Output files expected
- `viewport.mp4` — generated by `record.py` (automated render).
- `screen.mp4` — this manual OBS recording.
