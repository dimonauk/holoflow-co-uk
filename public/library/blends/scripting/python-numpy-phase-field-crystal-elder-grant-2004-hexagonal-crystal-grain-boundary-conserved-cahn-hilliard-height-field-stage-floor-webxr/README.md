# Phase-Field Crystal (PFC) Model — Elder & Grant 2004

**Blender 5.1 · Python/NumPy · Scripting · CC0**

A 128 × 128 height-field stage floor generated by the Phase-Field Crystal
model of Elder & Grant (2004). The density field ψ(r) self-organises into
a triangular crystal lattice through conserved Model B dynamics driven by
a free energy that selects a single preferred wavenumber k₀ = 1.

## Files

| File | Purpose |
|---|---|
| `blueprint.py` | Blender 5.1 Python script — runs four PFC simulations and builds the mesh with four shape keys |

## Shape Keys

| Name | Parameters | Physics |
|---|---|---|
| Basis | r=−0.25, ψ̄=−0.50, T=800 | Perfect hexagonal crystal lattice |
| SK_GrainBnd | r=−0.25, ψ̄=−0.50, T=600 | Polycrystalline, grain boundary where two nuclei meet |
| SK_Stripe | r=−0.07, ψ̄=−0.25, T=800 | Lamellar (stripe) phase — one wavevector, not three |
| SK_Coexist | r=−0.12, ψ̄=−0.38, T=300 | Liquid-crystal coexistence — partial ordering |

## Running

Open Blender 5.1, go to Scripting workspace, open `blueprint.py`,
press Alt+P. The script runs four simulations (~2–6 min) and exports
`pfc_crystal_floor.glb` alongside this README.

## Physics Summary

The PFC free energy F[ψ] = ∫{(ψ/2)[r+(1+∇²)²]ψ + ψ⁴/4} dr selects
a periodic ground state at wavenumber k₀ = 1 (lattice spacing a₀ = 4π/√3).
For r < 0 the crystal phase is favoured; r > 0 gives a stable liquid.
The conserved dynamics ∂ψ/∂t = ∇²[δF/δψ] preserve total density ψ̄.
An ETD1 Fourier spectral integrator provides unconditional stability of
the linear part.
