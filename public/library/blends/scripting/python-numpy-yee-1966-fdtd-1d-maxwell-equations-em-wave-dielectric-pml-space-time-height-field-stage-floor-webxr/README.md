# 1D FDTD Maxwell — Yee 1966 Staggered-Grid EM Wave Simulation

Blender 5.1 · Scripting · CC0

## What this is

A 128 × 128 space–time height-field visualisation of the 1D
Finite-Difference Time-Domain (FDTD) method introduced by K. S. Yee in 1966.
The x-axis of the mesh is spatial position; the y-axis is time; height encodes
E_z amplitude.  Four Blender shape keys capture distinct EM wave phenomena:

| Key | Scenario | Key physics |
|-----|----------|-------------|
| Basis | Free space, PEC walls | Pulse splits, bounces |
| SK_Dielectric | Half-space ε_r=4 | Fresnel r=−⅓ reflection |
| SK_Cavity | PEC cavity walls | Standing-wave resonance |
| SK_PML | CPML absorbing layers | Clean absorption, no echo |

## Files

| File | Purpose |
|------|---------|

| `record.py` | Run after blueprint — renders `viewport.mp4` (5 s) |
| `SCREEN-RECORDING-NOTES.md` | OBS instructions for `screen.mp4` |
| `fdtd_field_floor.blend` | Saved blend (generated by blueprint.py) |
| `fdtd_field_floor.glb` | Draco-6 GLB for WebXR (generated by blueprint.py) |

## Quick start

```
1. Open Blender 5.1
2. Scripting workspace → open blueprint.py → Run Script
3. Inspect shape keys in Layout workspace
4. (Optional) run record.py to render viewport.mp4
```
