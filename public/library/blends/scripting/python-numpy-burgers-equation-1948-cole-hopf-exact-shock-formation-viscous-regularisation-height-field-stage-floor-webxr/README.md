# Burgers Equation — Cole-Hopf Exact Solution, Shock Formation, Viscous Regularisation

**Blender 5.1 · Python + NumPy · CC0 · scripting/exact**

A 128 × 128 height-field stage floor encoding the space-time diagram of the
Burgers equation — the canonical PDE for nonlinear wave steepening, shock
formation, and viscous regularisation.  The x-axis is the spatial coordinate;
the y-axis is time (past at y = 0, future at +y); height encodes velocity
u(x, t).

The simulation uses the **Cole-Hopf transformation** (Hopf 1950; Cole 1951),
which converts Burgers to the heat equation via u = −2ν ∂ ln φ/∂x.  The heat
equation is solved **exactly** in Fourier space — no time-stepping, no
numerical dissipation.  Starting from u₀ = −sin(πx), a shock forms at x = 0
near t ≈ 0.318 = 1/π, visible as a near-vertical ridge on the floor.

## Exact solution method

The **Cole-Hopf transformation** u = −2ν ∂ ln φ/∂x converts Burgers to the
heat equation ∂φ/∂t = ν ∂²φ/∂x².

1. Compute θ(x) = ∫u₀ dξ via spectral integration: θ̂ = û₀/(ik), k ≠ 0.
2. Set φ₀ = exp(−θ/(2ν)) (subtract mean of θ to prevent float64 overflow).
3. Evolve exactly: φ̂(k,t) = φ̂₀(k) · exp(−νk²t).
4. Recover velocity: u = −2ν · IFFT(ik φ̂) / IFFT(φ̂).

**Shock time** for u₀ = −sin(πx): t_shock = 1/max|∂u₀/∂x| = 1/π ≈ 0.318.
**Rankine-Hugoniot condition**: shock speed s = (u⁺ + u⁻)/2 = 0 (stationary by symmetry).
**Viscous shock width**: δ ≈ 4ν/|u⁺ − u⁻|  (e.g. 0.04 for ν=0.010, |Δu|≈1).
