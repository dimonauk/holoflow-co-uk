# SSH Model — Su–Schrieffer–Heeger 1979

**Topic:** Topological Insulator · Zak Phase · Bulk–Edge Correspondence  
**Blender version:** 5.1  
**Technique:** Python + NumPy · 128×128 spectral-flow height-field · direct diagonalisation

## What this makes

A 128×128 height-field stage floor whose z-coordinate traces the energy eigenvalue
spectrum of the SSH tight-binding chain as the intercell hopping t₂ sweeps from
0.15 to 2.50 (with intracell hopping t₁ = 1.0 fixed).  Each row of the mesh is
one value of t₂/t₁; each column is one eigenstate, sorted by ascending energy.
The cobalt–amber gradient marks edge-state localisation: bulk states stay cobalt;
the two zero-energy modes that thread through the band gap for t₂ > t₁ glow amber.

## Shape keys

| Key | Boundary | Physics |
|-----|----------|---------|
| Basis | Open | Zero modes visible; amber threads cross mid-gap for t₂ > 1 |
| SK_Periodic | Periodic | Zero modes absent; gap closes cleanly at t₂ = t₁, no threading |
| SK_NNN | Open + t₃ = 0.30 | NNN hopping breaks sublattice symmetry; amber threads shift off E = 0 |
| SK_SymBreak | Open + δ = 0.40 | Staggered onsite (±δ) gaps the edge states entirely |

## Physics

```
H = Σ_n [t₁(c†_{nA}c_{nB} + h.c.) + t₂(c†_{n+1,A}c_{nB} + h.c.)]
E±(k) = ±√(t₁² + t₂² + 2t₁t₂ cos k)     two bands, gap = 2|t₁ − t₂|
Zak phase:    γ = 0 (t₁ > t₂, trivial),   γ = π (t₂ > t₁, topological)
Winding number: ν ∈ {0, 1}
Edge state decay:  ξ = 1 / |ln(t₁/t₂)| unit cells
Protected by chiral symmetry: {H, Γ} = 0,  Γ = diag(+1,−1,+1,−1,…)
```
