# BTW Abelian Sandpile — Self-Organised Criticality

**Blender 5.1 · Python / NumPy · CC0**

## What this is

A 128 × 128 height-field stage floor generated by the
Bak–Tang–Wiesenfeld (1987) Abelian Sandpile Model — the canonical
example of self-organised criticality (SOC). The system is driven to
its critical state without tuning any parameter; avalanche sizes then
follow a power law P(S) ~ S^{−1.11}.

## Shape keys

| Key | Description |
|---|---|
| Basis | Critical-state height field h ∈ {0, 1, 2, 3} |
| SK_SmallAval | Cluster of a small avalanche (5–35 cells) raised above the surface |
| SK_LargeAval | Cluster of a large (≥ 700-cell) system-spanning avalanche |
| SK_Maximal | All h = 3 — maximally stable uniform initial state |

## Physical parameters

| Constant | Value | Meaning |
|---|---|---|
| N | 128 | Grid side length |
| CRITICAL_HEIGHT | 4 | Toppling threshold |
| N_GRAIN_SETTLE | 1 200 000 | Grains to reach stationarity |
| τ (size exponent) | ≈ 1.11 | P(S) ~ S^{−τ} |
| D_f (fractal dim) | ≈ 2.75 | Hausdorff dimension of avalanche cluster |

## Running time

~1–3 minutes in Blender's Python interpreter (NumPy vectorised).
