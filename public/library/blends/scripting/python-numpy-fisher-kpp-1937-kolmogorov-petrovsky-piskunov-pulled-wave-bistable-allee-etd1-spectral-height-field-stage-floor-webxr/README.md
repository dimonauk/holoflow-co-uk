# Fisher-KPP Reaction-Diffusion Wavefront

**Blender 5.1 · Python / numpy · CC0 Public Domain**

## What this builds

A 128 × 128 height-field stage floor (`fisher_kpp_floor.blend` / `.glb`) whose
elevation encodes the population density *u(x, y)* of the Fisher-KPP
reaction-diffusion equation at four distinct moments / parameter regimes,
packaged as GLTF morph targets.

## The equation

```
∂u/∂t = D ∇²u  +  r · u(1 − u)          [monostable, KPP / pulled wave]
∂u/∂t = D ∇²u  +  r · u(1−u)(u − θ)     [bistable, Allee / pushed wave]
```

R.A. Fisher (1937) used the monostable form to model the spatial spread of
a gene with selective advantage *r* and diffusion coefficient *D*.
Kolmogorov, Petrovsky & Piskunov (1937) proved rigorously that any initial
perturbation with compact support generates a travelling wave whose speed
converges to the minimum *c\* = 2√(Dr)* — the "pulled" speed, because the
leading edge, where *u ≈ 0*, is driven by the linearised growth rate.

Adding the Allee factor *(u − θ)* makes *u = 0* a *stable* equilibrium.
A small nucleus goes extinct; only a large-enough initial colony (peak > θ)
generates a "pushed" wave that still propagates, though at a different speed.

## Numerical method

ETD1 (Exponential Time Differencing, first order) with the split:

```
Linear   L̂_k = −D k² + r      (absorbs linearised growth; exact in Fourier)
Nonlinear N(u) = −r u²          (KPP) | −r u²(1+θ−u)  (bistable split at f′(0))
û(t+Δt) = e^{L̂ Δt} û  +  φ₁(L̂ Δt) N̂(t) Δt
φ₁(z) = (eᶻ−1)/z              (Taylor-safe near z = 0)
```

Unconditionally stable for the linear part. Nonlinear stability:
`Δt · r ≪ 1` → `0.1 · 2.0 = 0.2 ≪ 1` ✓
