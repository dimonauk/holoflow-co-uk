# Screen Recording Notes — Drossel–Schwabl Forest Fire Model

## Output target

`public/library/videos/scripting/python-numpy-drossel-schwabl-1992-forest-fire-model-self-organised-criticality-fire-cluster-power-law-height-field-stage-floor-webxr/screen.mp4`

## Capture settings (OBS or Windows Game Bar)

| Setting | Value |
|---|---|
| Source | Window capture → Blender |
| Resolution | 1920 × 1080 |
| Frame rate | 30 fps |
| Audio | Disabled |
| Output format | MP4 (H.264, CRF 20) |

## Recording procedure

1. Open `drossel_schwabl_forest_floor.blend` (generated by `blueprint.py`).
2. Press **Numpad 5** → Orthographic. Press **Numpad 7** → top view.
3. Switch to **Material Preview** shading (press **Z** → Material Preview).
4. In the **Object Data Properties** panel, expand **Shape Keys**.
5. Start OBS recording.

### Take sequence (aim for ~30 s total):

| Duration | Action |
|---|---|
| 5 s | Show **Basis** shape key (value = 1.0). Orbit slowly with Middle Mouse Button. Narrate: "SOC steady state: ash patches, living forest, active fire cluster." |
| 5 s | Set **SK_LowP** → 1.0, Basis → 0.0. Orbit. Narrate: "Low regrowth rate — sparse savanna; fire clusters stay small below percolation threshold." |
| 5 s | Set **SK_HighP** → 1.0, SK_LowP → 0.0. Orbit. Narrate: "High regrowth rate — dense forest; infrequent but system-spanning fires." |
| 5 s | Set **SK_AllTrees** → 1.0, SK_HighP → 0.0. Narrate: "All sites forested — maximum height surface before the first lightning strike." |
| 5 s | Scrub slowly between shape keys to show the height transition across forest density regimes. |
| 5 s | Switch to **Rendered** shading. Final 3/4 orbit shot of the WebXR-ready stage floor. |

## Tips

- Keep the viewport at **Material Preview** with HDRI disabled for the clearest
  three-colour (cobalt ash / green forest / amber fire) appearance.
- Zoom slightly so the grid fills 80 % of the frame — the SOC fire clusters
  read as bright amber speckles against the green canopy.
- Slow the playback with **Timeline → Playback → Sync** set to
  "No Sync" if you want to scrub more smoothly during the shape-key transition take.
