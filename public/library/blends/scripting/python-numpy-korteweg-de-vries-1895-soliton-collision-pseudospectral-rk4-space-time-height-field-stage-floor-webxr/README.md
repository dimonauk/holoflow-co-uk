# KdV Soliton Collision — Space-Time Height-Field Stage Floor

**Blender 5.1 · Python + NumPy · CC0 · scripting/pseudospectral**

A 128 × 128 height-field stage floor encoding the space-time diagram of the
Korteweg–de Vries (KdV) equation — the canonical model for solitons in shallow
water and plasmas. The x-axis of the floor is the spatial coordinate; the y-axis
is time (past at −y, future at +y); height encodes wave amplitude u(x, t).

Solitons appear as inclined ridges on the floor. When two ridges cross, each
re-emerges intact — but shifted by the exact phase-shift formula from
inverse-scattering theory.

## Numerical method

Fourier pseudospectral with 2/3-rule dealiasing; 4th-order Runge–Kutta in
Fourier space with dt = 0.02.  Stability bound for RK4 on the imaginary axis:
dt ≤ 2√2 / k_max³_dealiased ≈ 0.038; dt = 0.02 leaves a factor of ×1.9 margin.

Wavenumber budget: N_X = 128 points on L = 64 domain → k_Nyquist = 2π ≈ 6.28;
after 2/3 dealiasing: effective k_max ≈ 4.19.
